# 👺 Like/Dislike Characters App

Sistema de votación para personajes de Rick and Morty, Pokémon y Superhéroes.

## 📁 Estructura del Proyecto
```
like-dislike-app/
├── backend/     # API REST con NestJS + TypeScript + MongoDB
└── frontend/    # Interfaz con React + TypeScript (en desarrollo)
```


## 📚 Documentación

Ver README de cada módulo:
- [Backend](./backend/README.md)

## 🛠️ Tecnologías

### Backend
- NestJS v10
- TypeScript
- MongoDB Atlas
- Mongoose

### Frontend (próximamente)

- TypeScript
- Vite
